rclone-vps-dr

rclone-vps-dr is a personal-use tool. It runs rclone on the owner's own server (VPS) to copy backup files of the owner's own data into the owner's own Google Drive, and to read them back for verification and restore.

  • Used only by its owner (single user). It is not offered to the public.
  • Google API scope: https://www.googleapis.com/auth/drive.file only — it can see and manage only the files it created itself. It cannot read other files in Google Drive.
  • No data is sold, shared with, or sent to any third party.

Privacy Policy — rclone-vps-dr

Last updated: 2026-11-16

rclone-vps-dr is a personal-use backup tool operated by its owner for the owner's own Google account only.

Data accessed

The tool requests only the Google Drive scope drive.file. With this scope it can access only the files and folders that the tool itself created in the owner's Google Drive. It does not access any other Google Drive files or any other Google user data.

Use of data

The files are the owner's own backup data. They are uploaded, listed, downloaded and compared only to keep and verify the owner's backups.

Storage and sharing

OAuth tokens are stored only on the owner's own server with owner-only file permissions. No data is sold, shared with, or transferred to any third party, and no data is used for advertising.

Revoking access

Access can be revoked at any time from the Google Account "Third-party apps & services" page.
